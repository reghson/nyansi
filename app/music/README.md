# Nyansi background music

calm, upbeat, dramatic and kids (stored as base64 text of AAC .m4a files, *.m4a.b64) are original loops made for Nyansi.
They were synthesised from scratch with code (simple oscillators, noise drums and reverb), with no samples
or recordings from anyone else, and are released under CC0 1.0 (public domain): free to use in any video.
